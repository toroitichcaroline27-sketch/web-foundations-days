About QuickNotes

QuickNotes is a lightweight web application designed to help software engineering students organize daily learning notes quickly and effortlessly. It provides a clean, distraction-free interface so you can focus entirely on capturing key concepts and code snippets.

How to use QuickNotes

  1. create a new note file inside your designated day directory .
  2. Format your notes using standard, valid HTML tags .
  3. save your file and view it in your browser using Live server .
